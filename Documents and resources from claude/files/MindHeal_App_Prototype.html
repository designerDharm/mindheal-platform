03. System Architecture
Three-tier architecture: Mobile App → Backend API → Data Layer
📱
Frontend Layer
Flutter (Dart) — Cross-platform mobile (iOS + Android)
Google Antigravity — Code generation & scaffolding
Stitch — UI component design system
Provider / Riverpod — State management
Agora Flutter SDK — Audio/Video calls
Flutter i18n — Multi-language support
flutter_pdf_viewer — In-app PDF rendering
firebase_messaging — Push notifications
⚙️
Backend Layer
Node.js + Express.js — REST API server
Socket.io — Real-time chat & signaling
Firebase Admin SDK — Auth verification
Anthropic Claude API — AI counselling & analysis
OpenAI Whisper — Voice-to-text transcription
PDFKit / Puppeteer — PDF report generation
Razorpay SDK — Payments & wallet
MSG91 — OTP delivery
Agora Token Server — Call session management
🗄️
Data Layer
PostgreSQL — Users, sessions, transactions, reports
Firebase Firestore — Real-time chat messages
Firebase Storage — Images, voice recordings, PDFs
Redis — Session cache, OTP store, rate limiting
Firebase Auth — Auth tokens & user identity
AWS S3 (optional) — Large file / PDF storage
CDN — Ambient sounds, videos, static assets

07. API Endpoints — REST Design
Core API routes for the User App — Base URL: /api/v1
🔐 Auth
POST/auth/registerEmail/phone register
POST/auth/loginLogin existing user
POST/auth/send-otpSend OTP via MSG91
POST/auth/verify-otpVerify OTP + issue JWT
POST/auth/googleGoogle OAuth callback
POST/auth/refresh-tokenRefresh JWT token
POST/auth/logoutInvalidate session
👤 User Profile
GET/user/meGet own profile
PUT/user/meUpdate profile
POST/user/avatarUpload avatar
PUT/user/languageChange app language
GET/user/notificationsList notifications
👨‍⚕️ Counsellors
GET/counsellorsList + filter counsellors
GET/counsellors/:idCounsellor profile
GET/counsellors/:id/slotsAvailable time slots
POST/sessions/bookBook a session
POST/sessions/call/tokenGet Agora call token
GET/sessions/myUser session history
POST/sessions/:id/reviewSubmit review
🤖 AI Services
POST/ai/chatSend message to AI
GET/ai/sessionsAI chat history
POST/analysis/dreamSubmit dream for analysis
POST/analysis/handwritingSubmit handwriting image
POST/analysis/signatureSubmit signature image
POST/analysis/:id/unlock-pdfPay & unlock PDF
GET/analysis/:id/pdfDownload PDF report
💳 Wallet & Payments
GET/wallet/balanceGet wallet balance
POST/wallet/topup/initInit Razorpay order
POST/wallet/topup/verifyVerify payment
GET/wallet/transactionsTransaction history
POST/payments/webhookRazorpay webhook
🧩 Wellness
GET/gamesList mind games
GET/soundsAmbient sounds list
GET/tipsMental health tips
GET/videosFocus/wellness videos
POST/mood/logLog mood entry
GET/mood/historyMood trend chart
