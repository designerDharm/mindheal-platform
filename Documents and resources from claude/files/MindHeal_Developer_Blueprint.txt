1. PROJECT OVERVIEW
1.1 Platform Summary
MindHeal is a full-stack psychological wellness platform consisting of three interconnected applications: a User
Mobile App, a Counsellor Mobile App, and a Web-based Admin Panel. The platform connects users seeking
mental health support with licensed human counsellors and AI-powered counselling services. All monetary
transactions are in Indian Rupees (INR).

2.4.3 Session Booking Flow
1. User selects counsellor and views available slots
2. User selects date, time, duration, and session type
3. System calculates fee = counsellor rate x duration
4. User confirms and pays from wallet (amount held/deducted)
5. System sends FCM notification to counsellor
6. Counsellor accepts or declines (with reason)
7. If declined, wallet amount is refunded instantly
8. Both parties receive reminders 30 min and 10 min before session
9. Post-session: user rates counsellor (1-5 stars + review text)

8. SECURITY & COMPLIANCE
8.1 Authentication & Authorisation
•
•
•
•
•

Firebase Auth for identity management (token issuance and verification)
Custom JWT (access token: 15 min, refresh token: 30 days) issued by backend
Refresh tokens stored in Redis (revocable on logout)
Role-based middleware: USER / COUNSELLOR / ADMIN roles enforced on every protected route
Admin routes protected by 2FA (TOTP) in addition to password

8.2 Data Security
•
•
•
•
•
•
•
•
•

All API keys encrypted with AES-256 before storage in PostgreSQL
Encryption key stored in backend environment variable (never in DB or codebase)
Firebase Storage rules: users can only access their own files
Firebase Firestore rules: users can only read/write their own chat rooms
HTTPS enforced everywhere (TLS 1.2+)
Passwords hashed with bcrypt (minimum 10 rounds)
OTP stored as SHA-256 hash in Redis with 5-minute TTL
Input validation with Joi on all API endpoints
SQL injection prevention via parameterised queries (pg library)

8.3 Rate Limiting
•
•
•
•
•

OTP send: max 3 requests per mobile/email per 10 minutes
Login attempts: max 5 failures per IP per 15 minutes (then 30-min block)
AI chat messages: admin-configurable daily limit per user (default 50)
API endpoints: 100 requests per minute per authenticated user
File upload: max 10MB per file, validated MIME types
